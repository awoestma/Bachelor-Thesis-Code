# Bachelor-Thesis-Code
This repository contains the code for data preparation (01_datapreparation_AW) and analysis (02_dataanalysis_AW) for my bachelor thesis. The dataset used for this analysis is not included in this repository due to data usage and licensing restrictions. 
The original data were provided by the "Deutsche Zentrum für Hochschul- und Wissenschaftsforschung" (DZHW). They sent me a SUF ("Scientific Use File") version of the data.
Apolinarski, B., Becker, K., Bornkessel, P., Brandt, T., Heißenberg, S., Middendorff, E., Naumann, H. & Poskowsky, J. (2019). 21st Social Survey (2016). Data Collection: 2016. Version: 2.0.0. Data Package Access Way: SUF: Download [Data set]. Hanover: FDZ-DZHW. Data curation: Baillet, F. & Weber, A. https://doi.org/10.21249/DZHW:ssy21:2.0.0
